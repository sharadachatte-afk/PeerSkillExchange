# 🤝 Peer Skills Exchange System

### Learn • Teach • Connect • Grow

## 📌 Project Overview

The **Peer Skills Exchange System** is a web-based platform that helps students connect with each other to **share knowledge and learn new skills**.

Students can create their profile, add the skills they can teach, mention the skills they want to learn, search for suitable peers, and send connection requests.

The system provides a simple environment for **peer-to-peer learning and knowledge sharing**.

---

## 🎯 Objectives

* Connect students based on their skills and interests.
* Allow students to share the skills they can teach.
* Help students find skills they want to learn.
* Provide skill-based peer matching.
* Allow users to send and manage connection requests.
* Provide profile management for students.
* Store user and request data using MongoDB.

---

## ✨ Key Features

### 👤 User Registration & Login
Students can create an account and securely log in to the system.

### 📊 Dashboard
A central page where users can access the main features of the application.

### 🔎 Find Peers
Users can search for students who can teach a particular skill.

### 🎯 Skill Matching
The system matches a user's learning skills with other users' teaching skills.

### 🤝 Connection Requests
Users can send requests to suitable peers and the receiver can accept or reject them.

### 👤 Profile Management
Users can update their name, department, year, teaching skills, and learning skills.
